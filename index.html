01 Введение

Интернет — сеть сетей

Слово Internet возникло как сокращение от Interconnected Networks — «объединённые сети» или «сеть сетей».

Первая версия была построена в 60-х годах XX века американскими военными. Задача: создать сеть, работоспособную при разрушении 70 % узлов.

У такой сети не должно быть центра, от которого зависит работа. Соединить каждый компьютер с каждым невозможно — нужно слишком много линий.

Решение — распределённая сеть из ячеек, как рыболовная сетка.

02 Архитектура

Маршрутизаторы и отсутствие центра

⟁ Маршрутизатор

Компьютер в узле сети, который направляет каждый пакет данных кратчайшим маршрутом по адресу в заголовке пакета. Если канал вышел из строя — пакет идёт по более длинному, но работающему пути.

⊘ Нет единого центра

В Интернете нет единого центра управления. Если бы он существовал, для разрушения всей сети было бы достаточно уничтожить этот центр.

⇅ Клиент-сервер

Информация хранится на серверах, связанных скоростными линиями (оптоволокно, спутники). Программа-клиент запрашивает данные, сервер возвращает ответ.

Маршрутизация: пакеты находят путь даже при обрыве линии

04 Протоколы

Протоколы TCP/IP

Протокол — набор правил обмена данными. Источник и приёмник обязаны использовать один и тот же протокол. В Интернете применяется семейство TCP/IP.

TCP — Transmission Control Protocol

Устанавливает соединение и обеспечивает доставку данных. Блок данных разбивается на пакеты (обычно не более 1,5 Кбайт).

IP — Internet Protocol

Устанавливает правила построения пакета и систему IP-адресов, по которым маршрутизаторы определяют маршруты движения пакетов.

Службы Интернета (WWW, e-mail и др.) используют свои протоколы «верхнего уровня» поверх TCP/IP.

HTTP, FTP, SMTP, DNS

05 Адресация

IP-адреса: IPv4

Каждый компьютер в Интернете должен иметь уникальный адрес. IP-адрес — это 32-битное число.

В IP-адресе закодированы номер сети и номер компьютера — как почтовый индекс и адрес улицы, дома, квартиры.

Каждое из четырёх чисел октета находится в диапазоне 0–255 (8 бит = 2⁸ значений).

IP-адрес присваивается каналу связи, а не компьютеру: у одного ПК может быть несколько адресов (сетевая карта + Wi-Fi).

IPv4: 32 бита, 4 октета, диапазон каждого 0–255
06 Новая версия

Переход на IPv6

Из-за бурного развития Интернета адресов IPv4 уже не хватает для всех желающих. Разработана новая система адресов — IPv6.

128 бит вместо 32

Адрес записывается в виде 8 групп по 4 шестнадцатеричные цифры, разделённые двоеточиями:

2001:0DB8:11A3:09D7:1F34:8A2E:07A0:765D

Количество адресов: 2¹²⁸ ≈ 3,4 × 10³⁸ — хватит надолго!

Полный переход на IPv6 займёт несколько лет: он потребует больших денежных затрат и замены всех устаревших устройств.

IPv6 решает проблему нехватки адресов
07 Домены

Доменные имена и DNS

Человеку неудобно работать с числовыми адресами — они плохо запоминаются. В 1984 году разработана система доменных имён DNS, позволившая использовать символьные имена сайтов: www.mail.ru

Домены образуют иерархию, вкладываясь друг в друга как матрёшки. Домены ru, рф, su принадлежат России; общие домены: com, net, org, biz, info, name, museum.

DNS-сервер

Хранит таблицы пар «IP-адрес ↔ доменное имя». Задача — по запросу клиента вернуть IP-адрес для заданного доменного имени (или наоборот).

Многозначные соответствия

Одному домену могут соответствовать несколько IP-адресов — распределение нагрузки (www.yandex.ru, www.google.com). Несколько небольших сайтов могут жить на одном IP-адресе.

DNS преобразует символьное имя в числовой IP-адрес
08 практика

Задачи: сборка IP-адреса

Учитель: нажмите «Показать ответ», чтобы открыть решение
Задача 1 · по номерам сети и узла
Компьютер подключён к сети номер 172.16.20, а его собственный номер в этой сети — 45. Соберите IP-адрес этого компьютера.
Подсказка: IP-адрес — это четыре числа от 0 до 255, разделённые точками: сначала номер сети, затем номер узла.
Правильный ответ
172.16.20.45
Решение: соединяем номер сети 172.16.20 и номер узла 45 через точку. Получаем четыре октета: 172 · 16 · 20 · 45. Это похоже на почтовый адрес: индекс (сеть) + улица и дом (узел).
Задача 2 · из двоичной записи
Дан 32-битный адрес в двоичном виде: 11000000.10101000.01101000.01110011. Переведите каждый октет в десятичную систему и соберите IP-адрес.
Подсказка: каждый октет — 8 бит; переведите его в десятичную систему (получится число от 0 до 255) и запишите октеты через точку.
Правильный ответ
192.168.104.115
Решение: 11000000₂ = 192 · 10101000₂ = 168 · 01101000₂ = 104 · 01110011₂ = 115. Записываем четыре числа через точку: 192.168.104.115.
09 практика

Задачи: сборка адреса сайта

Учитель: нажмите «Показать ответ», чтобы открыть решение
Задача 1 · из частей
Соберите адрес сайта из частей: протокол — https, имя сервера — www, домен второго уровня — mail, домен верхнего уровня — ru.
Подсказка: адрес читается по дереву доменов справа налево: страна → домен второго уровня → сервер. Протокол записывается первым и отделяется «://».
Правильный ответ
https://www.mail.ru
Решение: сначала протокол https://, затем слева направо от младшего к старшему домену: www (сервер) → mail (домен 2-го уровня) → ru (домен страны).
Задача 2 · элементы перепутаны
Элементы адреса сайта записаны вперемешку: com  ·  www  ·  https://  ·  google. Соберите из них полный правильный адрес.
Подсказка: найдите протокол (со «://»), затем имя сервера, домен второго уровня и в самом конце — домен верхнего уровня.
Правильный ответ
https://www.google.com
Решение: протокол https:// стоит первым; www — имя сервера; google — домен второго уровня; com — общий домен верхнего уровня. Порядок: протокол → сервер → домен → домен верхнего уровня.

Маршрутизация пакетов

Маршрутизаторы направляют каждый пакет кратчайшим путём. Если канал недоступен — пакет идёт по обходному маршруту. Данные собираются на стороне получателя.

Технология клиент-сервер

Программа-клиент (браузер) отправляет запрос. Сервер обрабатывает его и возвращает ответ. Практически все услуги Интернета работают по этой схеме.

11 итоги

Выводы

🌐 Интернет не имеет единого центра управления и никому не принадлежит. Это распределённая сеть, устойчивая к выходу из строя отдельных узлов.
⟁ Маршрутизатор — компьютер, пересылающий пакеты данных между участками сети по кратчайшему рабочему маршруту.
📦 Для обмена данными используются протоколы семейства TCP/IP. Каждая служба (WWW, e-mail) имеет свой протокол верхнего уровня.
🔢 IP-адрес — уникальный числовой адрес узла сети. IPv4 = 32 бита (4 октета 0–255), IPv6 = 128 бит (8 групп hex-цифр).
🏷️ Доменное имя — символьное имя сайта. Для преобразования доменных имён в IP-адреса используются DNS-серверы.
